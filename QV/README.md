# QV 面试练习室

根据当前 `query.md` 整理的个人面试题卡应用。初始包含 67 道完整问答，原答案和备考备注均保留。支持桌面与手机布局、浅色与深色主题，无网络依赖、无后端、无需账号。

## 打开方式

直接用 Chrome 或 Edge 打开本目录的 `index.html` 即可使用。请保留整个 QV 文件夹，不能只复制 HTML。

也可以使用本地服务，便于在固定地址保存学习记录：

```powershell
cd QV
node serve.cjs
```

然后打开 http://127.0.0.1:4173。按 Ctrl+C 停止服务。也可使用 `npm.cmd start`，无需 `npm install`。服务默认只监听本机。

浏览器按站点地址保存数据，直接打开文件和使用 localhost 是两个独立的存储空间。首次使用后建议固定同一种打开方式；切换时先备份再导入。

## 日常练习

- **闪卡练习**：按主题或关键词筛题，先回忆，再展开答案。可启动 60 秒口述计时，暂停或重新计时。
- **专注模式**：点击闪卡/列表切换旁的专注按钮，隐藏顶部概览，减少连续练习时的滚动；模式会保存。
- **掌握度**：展开后可标记“待复习”“有些印象”“已掌握”，自动前往下一题。在最后一题标记后停留于该题；导航不循环。
- **收藏与复习**：星标收藏重点题，在左侧“我的收藏”或“待复习”集中练习。学习状态是手动标记，不使用自动间隔复习算法。
- **个人笔记**：展开答案后记录自己的理解，自动保存。题目提供的“备考备注”与个人笔记分开存放。
- **题库管理**：列表阅读、编辑、删除或直接开始某道题。新增时可选择现有主题，也可输入新的主题。主题、状态、收藏与搜索可组合筛选。
- **随机练习**：打乱顺序后可随时恢复。每日已练按本地日期、不同已标记题目计数；单纯查看答案不算完成。

快捷键：Space 展开/收起；← / → 切题；S 收藏；1 / 2 / 3 标记；T 计时；/ 搜索；N 新增；E 编辑；? 打开帮助。输入文字或打开弹窗时，练习快捷键不会生效。

## 增加与修改问答

### 方法一 在页面中编辑

点击右上角“新增问题”，填写问题、主题、回答。标签和备注可选。点击题卡上的编辑图标可以修改原题。删除和放弃未保存修改都有二次确认。

### 方法二 导入 Markdown

点击“导入”，选择 `.md` 文件，或直接粘贴以下结构：

```markdown
## Agent 与工具

### 新的问题是什么？

**回答：**先写核心判断，再给出原因或项目例子。

> 备考备注（不口述）：[参考资料](https://example.com)
```

每个 `###` 标题代表一道题。编号可省略。正文支持多段回答，引用行作为备注。缺少答案的题会跳过，并在导入预览中提示。可以直接导入项目外的最新 `query.md`。

导入先预览，再确认。默认按 ID 或规范化后的问题文本去重，保留已有内容。选择“更新重复题内容”才会修改旧题的答案、备注等字段，并保留原有学习记录。相同问题可更新；改写后的问题会视为新题。

### 方法三 更新随项目分发的初始题库

在 QV 目录运行：

```powershell
node scripts/sync-data.cjs
# 或指定其他源文件
node scripts/sync-data.cjs "D:/notes/my-questions.md"
```

这会重新生成 `data/cards.js` 和 `data/query.md`。为保护已编辑内容，网页不会自动用初始题库覆盖浏览器内的数据。已有浏览器中请通过“导入”选择新的 Markdown；新浏览器会使用更新后的初始题库。

## 备份与恢复

- **完整备份 JSON**：包含全部问答、收藏、掌握度、练习次数、最后练习时间和个人笔记。推荐定期下载。
- **Markdown 导出**：全部问题、参考回答和备考备注，方便继续编辑；不包含个人笔记与学习记录。
- **合并导入 JSON**：默认只合并题目，不用备份覆盖当前学习记录。
- **完整恢复**：导入 QV 备份后勾选“完整恢复此备份”，二次确认后替换当前题库和学习记录。

数据通过 localStorage 保存在当前浏览器，网页编辑**不会直接修改磁盘上的 `query.md`**。更换浏览器、使用无痕模式、清理网站数据或移动文件路径可能使原存储不可见，请先备份。页面没有上传或同步数据的服务。若本地存储不可用，页面会提示未保存，仍可导出本次会话的数据。为避免多标签页覆盖，建议同时只在一个标签页编辑。

## 项目结构

```text
QV/
├── index.html              页面与弹窗
├── styles.css              响应式布局和主题
├── app.js                  界面、计时、存储和交互
├── core.js                 解析、校验、筛选、去重、统计
├── data/cards.js           可直接离线加载的初始题库
├── data/query.md           导入时的源文档快照
├── assets/favicon.svg      本地图标
├── scripts/sync-data.cjs   从 Markdown 生成初始题库
├── tests/core.test.cjs     数据与核心逻辑测试
├── tests/browser.cjs       浏览器端到端检查
├── serve.cjs               零依赖本地预览服务
├── package.json            启动与测试命令
└── README.md
```

## 验证与部署

核心测试使用 Node.js 内置测试器：`node --test tests/core.test.cjs`。覆盖源题库一致性、Markdown 往返导入导出、JSON 校验、去重、搜索组合与学习统计。

浏览器测试需要环境中已安装 Playwright，可用 `PLAYWRIGHT_MODULE` 指定其路径，`CHROME_PATH` 指定浏览器路径，再执行 `node tests/browser.cjs`。应用本身不依赖 Playwright。

全部页面资源均在本目录，无 CDN、在线字体或构建步骤。可将 QV 中的文件部署到 GitHub Pages 等静态托管服务。发布前请检查题库是否包含不宜公开的个人或项目内容。

交互参考：[AI 应用 / Agent 面经记忆卡](https://wzccwzzwcczw.github.io/ai-agent-flashcards/)。本项目独立实现界面和逻辑，题库来自用户的 `query.md`，没有复制参考站的题目或源代码。
